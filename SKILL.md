# Faceless Content Growth SOP Skill

## Overview

This skill turns faceless-content growth ideas into a direct operating system.
Use it when the user wants a practical plan, SOP, checklist, or monetization model for an AI-assisted faceless content business.

## When To Use

Trigger this skill for requests like:

- "build me a faceless content SOP"
- "how do I make money with faceless TikTok / YouTube / Reels"
- "compare service vs media models for faceless AI content"
- "turn these prompts into a workflow"
- "give me a launch checklist for AI UGC or faceless content"
- "design a cross-platform content engine"

## Workflow Decision

First decide which operating model fits the user's goal:

- If the user wants faster cash flow, client work, retainers, or brand deliverables, use the service-led path in [references/service-led.md](references/service-led.md).
- If the user wants audience assets, platform monetization, affiliate revenue, automation, or multi-platform publishing, use the media-led path in [references/media-led.md](references/media-led.md).
- If the user wants both, start from [references/hybrid-plan.md](references/hybrid-plan.md) and then load the two mode files selectively.

Before producing a plan, read [references/positioning.md](references/positioning.md) to frame the tradeoff clearly.

## Output Rules

When using this skill, produce outputs that are directly executable:

- Prefer concrete weekly and monthly operating steps over generic advice.
- Include channel choices, posting cadence, monetization layers, and the first acquisition path.
- Convert prompts into named assets the user can reuse immediately.
- Use tables when comparing niches, costs, timelines, or revenue models.
- Flag speculative revenue claims as examples or claimed benchmarks, not facts.

## Minimal Process

1. Identify the business model: service-led, media-led, or hybrid.
2. Choose one niche using [references/tables.md](references/tables.md) and [references/checklists.md](references/checklists.md).
3. Build the first 30-day execution plan using the relevant SOP file.
4. Pull the necessary prompts from [references/prompts.md](references/prompts.md).
5. Add the operating checklist from [references/checklists.md](references/checklists.md).
6. Add the monetization stack and cost tables from [references/tables.md](references/tables.md).

# Prompt Library

Use these prompts directly or adapt them to the user's niche.

## Niche Selection Prompt

```text
Act as a multi-platform content strategist.

I want to launch a faceless content brand across YouTube long form,
YouTube Shorts, TikTok, and Instagram Reels.

Analyze these niches: [list 5 to 7 niches]

For each, score from 1 to 10 on:
1. YouTube RPM potential
2. Affiliate or commerce potential
3. Short-form visual demonstration potential
4. Long-form storytelling depth
5. Audience purchase intent
6. Competition saturation

Then give me:
- the best cross-platform niche
- the best service-led niche
- the best media-led niche
- one under-served sub-niche
```

## Persona Prompt

```text
I am building a faceless account in the [niche] space.
Help me develop a clear account identity.

Generate:
1. Account name and handle
2. A 100-character bio
3. Three content pillars
4. Tone and visual style
5. Three repeatable opening hooks

Keep it specific to [niche]. Avoid generic creator language.
```

## Service Script Prompt

```text
You are a UGC scriptwriter for performance-focused DTC brands.
Write five 30-second scripts for a faceless UGC account in the [niche] space.

For each script include:
- hook
- target problem
- solution angle
- visual notes
- caption overlay
- soft CTA

Make each script feel different.
```

## Cross-Platform Script Prompt

```text
You are a senior multi-platform scriptwriter for faceless content brands.

Topic: [topic]
Target audience: [audience]
Niche: [niche]
Channel voice: [voice]

Output:
1. One 8-10 minute YouTube script
2. Four short-form scripts
3. Three caption variants per short
4. One long-form title and four short hooks
5. Three thumbnail concepts
```

## Metadata Prompt

```text
Act as a cross-platform SEO specialist.

Video topic: [topic]
Niche: [niche]
Script summary: [summary]
Hook line: [hook]

Output valid JSON only with:
- YouTube title, description, tags, chapters, pinned comment
- Instagram caption and cover text
- TikTok caption and cover text
```

## Brand Prospecting Prompt

```text
Find me 20 [niche] brands actively running paid ads on TikTok or Instagram.

For each one identify:
- brand name
- website
- current creative style
- one creative gap
- likely budget tier

Then draft a personalized cold email for each brand offering a single test video.
Keep each email under 100 words.
```

## Brand Outreach Prompt

```text
Write a 3-paragraph pitch to a brand named [brand].

I run a faceless content brand in [niche] across YouTube, TikTok, and Instagram.
My combined monthly reach is [X] views.
My audience is [audience description].

The pitch must:
- open with a specific compliment
- pitch a 3-video package
- explain why the audience converts
- end with one clear ask
```

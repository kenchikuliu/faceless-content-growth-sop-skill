# Hybrid Plan

Use this reference when the user wants one operating system that combines service revenue with media-asset growth.

## Hybrid Thesis

The fastest durable stack is:

- service cash flow first
- shared production assets
- media monetization layered in afterward

## Shared Asset System

Build one production system that feeds both sides:

| Asset | Service Use | Media Use |
| --- | --- | --- |
| Niche research | Identify buyers and ad angles | Choose channel topic clusters |
| Hook library | Improve client deliverables | Improve short-form retention |
| Script bank | Produce paid creative | Produce channel content |
| Proof clips | Sales collateral | Public distribution |
| Analytics | Show conversion hypotheses to brands | Choose future topics |

## Recommended 90-Day Sequence

### Days 1-30

- Pick one niche
- Build account identity
- Make sample videos
- Start daily publishing
- Start outbound to brands

### Days 31-60

- Close test projects
- Publish consistent repurposed content
- Refine hooks and production speed
- Add affiliate links where natural

### Days 61-90

- Push retainers
- Expand content into long-form plus shorts
- Introduce automation only after stable manual publishing
- Add first digital product or sponsor pitch if audience signals support it

## Default Recommendation

If the user is unsure, use this order:

1. Start service-led for cash flow.
2. Use the same niche and proof content to build media channels.
3. Add media monetization after output consistency exists.

## What To Deliver

For hybrid requests, always produce:

- a 30-day plan
- a weekly cadence
- a first monetization ladder
- a shared asset map
- a risk list for both sides

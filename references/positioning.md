# Positioning

Use this reference to decide which operating model fits the user's goal.

## Service-Led Model

Best when the user wants:

- Faster revenue without waiting for platform monetization thresholds
- B2B client work
- AI UGC production for brands
- Retainers, test projects, and outbound prospecting

Core economics:

- Content is proof and sales collateral
- Audience size matters less than niche clarity and deliverable quality
- Monetization comes from projects and retainers

Main risks:

- Client acquisition dependency
- Quality-control pressure on deliverables
- Niche and brand acceptance of AI-generated assets

## Media-Led Model

Best when the user wants:

- Owned audience and channel assets
- Cross-platform content repurposing
- Ad revenue, affiliate, creator rewards, sponsorships, and digital products
- Publishing automation

Core economics:

- Distribution is the engine
- One idea is repurposed into multiple assets
- Monetization stacks across several revenue lines

Main risks:

- Platform-policy volatility
- Slower time to meaningful income
- More setup complexity around production and automation

## Hybrid Model

Best when the user wants:

- Service cash flow in the short term
- Audience and media assets in the medium term
- A single research and scripting pipeline serving both goals

Core logic:

- Use service work to fund tools and production
- Use media channels as proof, lead-gen, affiliate surface, and future sponsorship inventory
- Reuse scripts, clips, and niche research across both tracks

## Short Decision Rule

Use this simple chooser:

| User Goal | Best Starting Model |
| --- | --- |
| Need money fastest | Service-led |
| Want asset-building and diversification | Media-led |
| Want both and can handle more complexity | Hybrid |

## Output Framing

When answering, describe the model directly:

- Service-led: "This is a service business using content as acquisition."
- Media-led: "This is a media business using content as the product engine."
- Hybrid: "This is a service-plus-media stack with shared production assets."

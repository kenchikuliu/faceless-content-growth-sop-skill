# Service-Led SOP

Use this reference when the user wants an AI UGC service business.

## Objective

Sell AI-assisted UGC-style creative output to brands, then move from one-off projects into retainers.

## 30-Day Build Sequence

### Week 1: Pick Niche and Offer

1. Pick one niche with visible ad spend and repeat content demand.
2. Define one narrow offer: short-form AI UGC for ads, landing pages, or organic social.
3. Set a simple packaging model: test project plus retainer upgrade path.

## Week 2: Build Persona and Production System

1. Create one account identity tied tightly to the niche.
2. Define 3 content pillars and 3 repeatable hook styles.
3. Build the first 5 scripts and 3 sample videos.

## Week 3: Publish Proof and Build Prospecting List

1. Post one video per day to the chosen proof channels.
2. Build a list of 20 target brands already running paid ads.
3. Note their current UGC style, creative gaps, and likely budget tier.

## Week 4: Start Sales Motion

1. Run inbound and outbound in parallel.
2. Add a simple bio link or one-page rate sheet with examples.
3. Pitch a single test video first, then upsell into a monthly retainer after results or approvals.

## Core Delivery Workflow

| Step | Action | Output |
| --- | --- | --- |
| 1 | Pick a niche | One clear buyer category |
| 2 | Build account identity | Handle, bio, pillars, hook system |
| 3 | Generate scripts | 5 short-form scripts |
| 4 | Produce videos | 30-second AI UGC clips |
| 5 | Publish proof content | Portfolio and credibility surface |
| 6 | Prospect brands | Outbound lead list |
| 7 | Sell test project | First paid deliverable |
| 8 | Convert to retainer | Recurring revenue |

## Recommended Offer Ladder

| Offer | Purpose |
| --- | --- |
| 1 sample / test video | Low-friction first sale |
| 3-video starter pack | Easier upsell from a successful test |
| Monthly retainer | Stable recurring revenue |

## Non-Negotiables

- Stay in one niche until deal flow is real.
- Use published content as proof, not just as growth content.
- Run outbound before waiting for inbound.
- Keep the primary promise tied to deliverables and outcomes, not AI novelty.

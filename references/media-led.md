# Media-Led SOP

Use this reference when the user wants a faceless media engine across YouTube, TikTok, and Instagram.

## Objective

Turn one idea into long-form, short-form, and metadata assets that monetize across multiple revenue lines.

## Core Operating Principle

One topic should produce:

- 1 long-form YouTube asset
- 3 to 4 short-form assets
- platform-specific metadata
- monetization surfaces across ads, affiliate, sponsorship, and products

## Weekly Production Loop

| Day | Output | Notes |
| --- | --- | --- |
| Monday | 1 long-form YouTube video | New topic |
| Tuesday | 1 TikTok + 1 Reel | Derived from Monday |
| Wednesday | 1 YouTube Short | Derived from Monday |
| Thursday | 1 TikTok + 1 Reel | Different angle |
| Friday | 1 YouTube Short | Another angle |
| Saturday | 2 TikToks + 1 Reel | Engagement or polling content |
| Sunday | Analytics review | Choose next angle |

## Production Pipeline

| Stage | Tool / Layer | Output |
| --- | --- | --- |
| 1 | Research and angle selection | Topic direction |
| 2 | Long-form scriptwriting | 8-12 minute script |
| 3 | Voiceover | Audio master |
| 4 | Assembly | Long-form video |
| 5 | Short extraction | 3-4 short scripts |
| 6 | Short editing | Vertical clips |
| 7 | Metadata generation | Titles, descriptions, captions |
| 8 | Publishing / scheduling | Multi-platform distribution |

## Monetization Layering Order

1. Publish first, no monetization pressure.
2. Add YouTube AdSense and affiliate links.
3. Add TikTok Shop or equivalent commerce layer.
4. Add brand deals once audience proof exists.
5. Add a simple digital product once trust is real.

## Non-Negotiables

- Do not treat each platform as a separate brand.
- Rework captions and on-screen text between TikTok and Reels.
- Track which clip angles outperform, then feed them back into long-form topics.
- Do not automate publishing before the manual workflow is stable.

# Checklists

## Model Selection Checklist

- Does the user need revenue fast
- Does the user want B2B clients or owned audience
- Can the user sustain daily or weekly publishing
- Can the user tolerate platform volatility
- Can the user handle operational complexity

## 7-Day Launch Checklist

| Day | Task |
| --- | --- |
| 1 | Pick model: service-led, media-led, or hybrid |
| 2 | Pick one niche and define one primary offer or channel promise |
| 3 | Create account identity, pillars, and hook library |
| 4 | Draft first scripts and produce first sample assets |
| 5 | Publish first content and create tracking sheet |
| 6 | Build monetization surface: rate card, affiliate layer, or both |
| 7 | Review outputs, gaps, and next 14-day cadence |

## Service-Led Weekly Ops

- Publish proof content daily or near-daily
- Add brands to outbound list
- Send prospecting emails or DMs
- Produce sample or paid clips
- Update rate sheet and proof page
- Review which pitches got replies

## Media-Led Weekly Ops

- Publish one long-form anchor asset
- Repurpose into multiple short clips
- Refresh titles, descriptions, and captions
- Review retention, CTR, and monetization surface performance
- Pick next week topics from best-performing angles

## Hybrid Weekly Ops

- Use one research topic across both service and media sides
- Publish proof clips publicly
- Use the best public clips in outbound
- Close paid work first, then fold lessons back into channel content
- Track time spent on delivery versus audience growth

## Monthly Review Checklist

- Which niche angle produced the best response
- Which channel or offer produced the best economics
- Which prompt or workflow caused bottlenecks
- Whether to narrow further or expand one layer
- Whether to add a new monetization layer

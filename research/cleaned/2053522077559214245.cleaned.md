## 3. PROMPT: niche selection

I picked a niche I liked the first time. Got crushed. The niche has to win on three filters: it has to monetize, it has to be visually demonstrable for short form, and it has to have enough depth for long form YouTube. Most niches fail at least one.

Run this before you build anything:

```
Act as a multi platform content strategist.

I want to launch a faceless content brand running on YouTube long form,

Analyze these niches: [list 5 to 7 niches]

For each, score from 1 to 10 on:
1. YouTube RPM potential
2. TikTok Shop product availability
3. Instagram Reels engagement curve
4. Visual demonstration potential
5. Long form storytelling depth
6. Audience purchase intent
7. Competition saturation

Then give me:
- the one niche that wins on all three platforms
- the niche that wins only on YouTube
- the niche that wins only on short form
- one untapped sub niche nobody is doing across all three

Final recommendation with reasoning.
```

## 5. PROMPT: master cross platform script

This single prompt does most of the heavy lifting. It outputs a long form YouTube script and the four short form clips at the same time, so nothing is wasted.

```
You are a senior multi platform scriptwriter for faceless content brands.

Topic: [topic]
Target audience: [audience]
Niche: [niche]
Channel voice: [educational and direct, or storytelling, or list based]

Output the following in order:

1. LONG FORM YOUTUBE SCRIPT (8 to 10 minutes)
   - Hook: pattern interrupt in the first 20 seconds, no greeting
   - Open loop: tease the payoff at the start
   - Body: 4 to 6 sections with [VISUAL: description] tags
   - Soft CTA at the end (no begging)
   - Spoken English, not essay English
   - Include [PAUSE] markers

2. FOUR VERTICAL SHORT SCRIPTS (45 to 60 seconds each)
   Each script must:
   - Open with a 3 second hook that works without sound
   - Cover ONE single insight from the long form
   - End with a curiosity gap, not a sales line
   - Include on screen text directions
   - Include a vertical visual cue for every 5 seconds

3. FOR EACH SHORT, GIVE THREE CAPTION VARIATIONS
   - One for TikTok (loose, 100 chars, no hashtag spam)
   - One for Instagram Reels (medium, hook in first line, 5 hashtags)
   - One for YouTube Shorts (SEO heavy, includes keyword, 3 hashtags)

4. TITLES
   - Long form YouTube title (under 60 chars, curiosity hook)
   - 4 short form hooks (one per short, under 50 chars)

5. ESTIMATED TOTAL RUNTIME and 3 thumbnail concepts for the long form

Optimize for: cross platform repurposing without each piece feeling recycled.
```

This single prompt replaces a scriptwriter at $200 per video, a social media manager at $40 per post, and an SEO specialist at $50 per upload. One run, a week of content.

## 7. PROMPT: platform specific metadata in JSON

I had a video with 600 views that should have had 60,000. Script was solid. Voice was clean. Title was a disaster.

Each platform wants different metadata. This prompt handles all three at once, and outputs everything as JSON so the auto publishing script in Part 11 can read it directly.

```
Act as a cross platform SEO specialist.

Video topic: [topic]
Niche: [niche]
Script summary: [3 sentence summary]
Hook line: [your opening line]

Output ONLY valid JSON, no markdown fences, no preamble, in this exact schema:

{
  "youtube": {
    "title": "under 60 chars, includes main keyword, curiosity trigger",
    "description": "250 words, SEO optimized, includes timestamps, 3 affiliate placeholder links, soft CTA",
    "tags": ["array", "of", "15", "tags", "broad", "to", "specific"],
    "category": "22",
    "privacy": "public",
    "chapters": [
      {"timestamp": "00:00", "title": "chapter title"}
    ],
    "pinned_comment": "single comment that boosts engagement"
  },
  "instagram": {
    "caption": "200 words, hook in first line, story driven, soft CTA, 8 hashtags at end",
    "cover_text": "4 words max, high contrast"
  },
  "tiktok": {
    "caption": "under 100 chars including hashtags, conversational, no marketing tone, 5 hashtags",
    "cover_text": "4 words max, high contrast"
  }
}

Critical rules:
- Output JSON only
- All strings must escape internal quotes properly
- TikTok caption character limit is hard
- Each platform caption must read native to that platform, not translated
```

You will see in Part 11 why JSON output matters. The script literally reads this file.

```
Thursday     1 TikTok + 1 Reel        different angle of same long form

```

One new long form per week and twelve to fourteen short form pieces, all from the same source. Total time: 4 to 5 hours including the long form. The algorithm on each platform sees consistent posting and starts pushing.

The one rule I never break: do not post the exact same vertical clip on TikTok and Instagram Reels on the same day. The platforms detect it and demote both. Either rework the captions and on screen text, or stagger by 48 hours.

## 10. Seven mistakes that cost me three months

I will save you the lessons I paid for.

- One. Posting on all three platforms before any one of them was working. Nail YouTube long form first, then layer short form on top.

- Two. Trying to grow each platform separately. They are not separate channels. They are one brand. Same name, same logo, same voice, same colors across all three.

- Three. Skipping analytics for the first 60 days. The data tells you exactly what to make next. If a TikTok of a specific section of your long form blows up, that exact angle is your next long form.

- Four. Using the same opening hook on all three platforms. YouTube wants curiosity. TikTok wants a pattern interrupt. Instagram wants emotional resonance. Different platforms, different brain modes.

- Five. Quitting at video 15. The cross platform algorithm needs roughly 25 to 30 pieces of content before it understands what you are about. Most people quit at 12.

- Six. Running ads to grow before the system was profitable organically. If it does not work organic, paid will not save it.

- Seven. Outsourcing the script to a freelancer at $200 a pop. Claude writes a better script for $0.05 in API costs and never misses the brief.

## 11. BONUS: auto publishing pipeline (Claude prompt + Python script)

This is the part nobody else writes about. Once you stop manually uploading to three platforms, the whole system unlocks. You stop being a content creator and become a content engineer.

The architecture:

```
Finished long video (mp4)  +  Vertical short (mp4)  +  meta.json
                          \         |         /
                           \        |        /
                            v       v       v
                      publish.py orchestrator
                      |          |          |
                      v          v          v
                  YouTube    Instagram    TikTok
                  Data API   Graph API   Content API
```

One command, three platforms, zero clicks. Here is the full working script.

> Step 1: Generate the metadata JSON

Use the metadata prompt from Part 7. Save Claude's output as meta.json next to your video files. The script below reads from that file directly.

> Step 2: The Python orchestrator

Save this as publish.py. Install once with pip install google-auth google-auth-oauthlib google-api-python-client requests.

```
"""
publish.py
Posts one video to YouTube, Instagram and TikTok in a single command.

Usage:
    python publish.py --video ./out/video.mp4 \
                      --short-video ./out/short.mp4 \
                      --short-public-url https://your.cdn/short.mp4 \
                      --metadata ./out/meta.json

Required env vars:
    YT_CLIENT_SECRETS    path to OAuth client secrets JSON from Google Cloud
    IG_USER_ID           Instagram Business account ID
    IG_ACCESS_TOKEN      long lived Graph API token
    TT_ACCESS_TOKEN      TikTok Content Posting API token
"""

import os, json, time, argparse, requests
from googleapiclient.discovery import build
from googleapiclient.http import MediaFileUpload
from google_auth_oauthlib.flow import InstalledAppFlow
from google.auth.transport.requests import Request
from google.oauth2.credentials import Credentials


def upload_youtube(video_path, meta):
    SCOPES = ["https://www.googleapis.com/auth/youtube.upload"]
    creds = None
    if os.path.exists("yt_token.json"):
        creds = Credentials.from_authorized_user_file("yt_token.json", SCOPES)
    if not creds or not creds.valid:
        if creds and creds.expired and creds.refresh_token:
            creds.refresh(Request())
        else:
            flow = InstalledAppFlow.from_client_secrets_file(
                os.environ["YT_CLIENT_SECRETS"], SCOPES)
            creds = flow.run_local_server(port=0)
        with open("yt_token.json", "w") as f:
            f.write(creds.to_json())

    yt = build("youtube", "v3", credentials=creds)
    body = {
        "snippet": {
            "title": meta["youtube"]["title"],
            "description": meta["youtube"]["description"],
            "tags": meta["youtube"]["tags"],
            "categoryId": meta["youtube"].get("category", "22"),
        },
        "status": {
            "privacyStatus": meta["youtube"].get("privacy", "public"),
            "selfDeclaredMadeForKids": False,
        },
    }
    media = MediaFileUpload(video_path, chunksize=-1, resumable=True)
    request = yt.videos().insert(part="snippet,status", body=body, media_body=media)
    response = None
    while response is None:
        status, response = request.next_chunk()
        if status:
            print(f"  YouTube {int(status.progress() * 100)}%")
    return f"https://youtu.be/{response['id']}"


def upload_instagram(public_video_url, meta):
    user_id = os.environ["IG_USER_ID"]
    token = os.environ["IG_ACCESS_TOKEN"]

    create = requests.post(
        f"https://graph.facebook.com/v19.0/{user_id}/media",
        data={
            "media_type": "REELS",
            "video_url": public_video_url,
            "caption": meta["instagram"]["caption"],
            "access_token": token,
        },
    ).json()
    container_id = create["id"]

    for _ in range(20):
        s = requests.get(
            f"https://graph.facebook.com/v19.0/{container_id}",
            params={"fields": "status_code", "access_token": token},
        ).json()
        if s.get("status_code") == "FINISHED":
            break
        time.sleep(15)

    publish = requests.post(
        f"https://graph.facebook.com/v19.0/{user_id}/media_publish",
        data={"creation_id": container_id, "access_token": token},
    ).json()
    return publish.get("id")


def upload_tiktok(video_path, meta):
    token = os.environ["TT_ACCESS_TOKEN"]
    file_size = os.path.getsize(video_path)

    init = requests.post(
        "https://open.tiktokapis.com/v2/post/publish/video/init/",
        headers={"Authorization": f"Bearer {token}"},
        json={
            "post_info": {
                "title": meta["tiktok"]["caption"],
                "privacy_level": "PUBLIC_TO_EVERYONE",
                "disable_duet": False,
                "disable_comment": False,
                "disable_stitch": False,
            },
            "source_info": {
                "source": "FILE_UPLOAD",
                "video_size": file_size,
                "chunk_size": file_size,
                "total_chunk_count": 1,
            },
        },
    ).json()
    upload_url = init["data"]["upload_url"]
    publish_id = init["data"]["publish_id"]

    with open(video_path, "rb") as f:
        requests.put(
            upload_url,
            headers={
                "Content-Range": f"bytes 0-{file_size - 1}/{file_size}",
                "Content-Type": "video/mp4",
            },
            data=f.read(),
        )
    return publish_id


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--video", required=True, help="Long form mp4")
    p.add_argument("--short-video", required=True, help="Vertical 9:16 mp4")
    p.add_argument("--short-public-url", required=True, help="Public URL for IG")
    p.add_argument("--metadata", required=True, help="meta.json from Claude")
    args = p.parse_args()

    with open(args.metadata) as f:
        meta = json.load(f)

    results = {}
    for name, fn in [
        ("youtube", lambda: upload_youtube(args.video, meta)),
        ("instagram", lambda: upload_instagram(args.short_public_url, meta)),
        ("tiktok", lambda: upload_tiktok(args.short_video, meta)),
    ]:
        print(f">>> {name}")
        try:
            results[name] = fn()
            print(f"  done: {results[name]}")
        except Exception as e:
            results[name] = f"failed: {e}"
            print(f"  failed: {e}")

    print("\n=== Results ===")
    print(json.dumps(results, indent=2))


if __name__ == "__main__":
    main()
```

Step 3: API access reality check

Honest version. Each platform requires setup before the script works the first time.

YouTube. Easiest. Create a Google Cloud project, enable YouTube Data API v3, download OAuth client secrets, set the path as YT_CLIENT_SECRETS. First run opens a browser, you authorize once, the token saves to yt_token.json. Daily upload quota is small by default, you apply for more inside the API console.

Instagram. Medium. You need a Business or Creator account, connected to a Facebook Page, plus a Meta developer app with Instagram Graph API permissions. Generate a long lived access token (60 days) from Graph API Explorer. Instagram Reels require the video to be publicly accessible by URL, so host on Cloudflare R2, S3 or a simple Bunny CDN bucket.

TikTok. Hardest. Apply to TikTok for Developers, request the Content Posting API direct post scope. Approval takes a few days. Until then, use the sandbox (videos are uploaded as private drafts) for testing.

If you want to skip the API setup entirely, the no code path is real. Use n8n (self hosted, free) or Make.com ($9 per month). Both have native nodes for all three platforms. The flow is identical: Webhook trigger receives a folder path, reads meta.json, posts to YouTube + IG + TikTok in three parallel branches. You build it once in 30 minutes and never touch it again.

## 12. Scheduling the whole thing on autopilot

Once publish.py works, schedule it. Two options.

Option A, your own machine. Cron on Linux or Mac. Open crontab -e and add:

```
0 14 * * 1 cd /home/you/factory && python publish.py --video out/week42.mp4 --short-video out/week42_short.mp4 --short-public-url https://cdn.you/short42.mp4 --metadata out/week42_meta.json
```

That runs every Monday at 14:00. Pre stage your videos on Sunday, the rest is automatic.

Option B, GitHub Actions, free for public repos and reasonable for private. Create .github/workflows/publish.yml:

```
name: weekly publish
on:
  schedule:
    - cron: "0 14 * * 1"
  workflow_dispatch:

jobs:
  ship:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: pip install google-auth google-auth-oauthlib google-api-python-client requests
      - run: |
          python publish.py \
            --video out/this_week.mp4 \
            --short-video out/this_week_short.mp4 \
            --short-public-url ${{ secrets.SHORT_URL }} \
            --metadata out/this_week_meta.json
        env:
          YT_CLIENT_SECRETS: ${{ secrets.YT_CLIENT_SECRETS }}
          IG_USER_ID: ${{ secrets.IG_USER_ID }}
          IG_ACCESS_TOKEN: ${{ secrets.IG_ACCESS_TOKEN }}
          TT_ACCESS_TOKEN: ${{ secrets.TT_ACCESS_TOKEN }}
```

Drop the API tokens into repository Secrets, push the videos to the repo or a connected storage bucket, the workflow runs every Monday with no machine of yours involved.

This is what hands free actually looks like. The only manual step left in the entire pipeline is approving Claude's script and naming the output file. Everything else is automatic.
